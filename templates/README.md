except the capstone write-up, and your numbers are the deliverable, not a perfect match with anyone
else's.

## How to fill one in honestly

- Name the machine. "My ThinkPad, 16 GB DDR4-5600, one stick" beats "my laptop".
- Write the number you got, not the number you hoped for. A 3.1 tokens/s result on a Pi 5 is a
  useful result; a rounded-up 10 is not.
- Keep the raw `homelab.py bench` output next to the table. It is the evidence, and you will want it
  again when the software changes.
- If a number is cited rather than measured, say so and name the source machine.
