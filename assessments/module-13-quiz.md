# Module 13 quiz

Nine scenario questions about defending a design. These are about the capstone, but the answers are
mostly about the habit of wanting evidence: which criterion fails, what a number has to be to
count, and which claims are assertions wearing a measurement's clothes.

**Pass mark: 70%.** You need 7 of 9. The practical capstone itself is graded against the
[rubric](capstone-rubric.md), not against this quiz.
