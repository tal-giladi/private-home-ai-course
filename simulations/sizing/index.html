Why

This is an estimate, not a measurement. It ignores cache behaviour, other processes, thermal throttling and the software's own overheads, and real machines land anywhere from 50% to 80% of the raw bandwidth figure. Run python homelab.py bench and use that number instead. This page exists to make you predict before you measure, and to make the prediction wrong in an interesting way.
